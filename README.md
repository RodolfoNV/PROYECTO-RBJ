# PROYECTO-RBJ (Logihtec v3)

Este proyecto es una plataforma de préstamos descentralizada en Stellar.

## 🚀 Despliegue Rápido del Backend

[![Deploy on Railway](https://railway.app/button.svg)](https://railway.app/template/new?repo=https://github.com/RodolfoNV/PROYECTO-RBJ&folder=server)

Al pulsar el botón:
1. Conecta tu cuenta de GitHub.
2. Railway detectará la carpeta `server/`.
3. Añade un servicio de **MySQL**.
4. Railway inyectará automáticamente las variables de entorno si las configuras en el panel.

## 💻 Desarrollo Local

### Servidor
```bash
cd server
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
